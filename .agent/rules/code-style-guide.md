# Code style guide

## General

- Make a component directory contains a `index.tsx` and `styles.module.css` for each component

## CSS

- using BEM naming style
- using CSS variables for theme
- do not output any unnecessary comments in CSS files

## TypeScript

- using TypeScript for type checking
- using type inference when possible
- do not output any unnecessary comments in TypeScript files
